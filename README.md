# Автоматизация бизнес-процессов автосервиса
## Введение
*Информационная система для автоматизации работы автосервиса.*
---
***Цель проекта - создать систему для управления :***
- клиентами;
- автомобилями;
- услугами;
- запчастями;
- записью на обслуживание;
- оплатой.
---
### Задачи проекта
1. Проанализировать бизнес-процессы автосервиса.
2. Спроектировать информационную систему.
3. Создать базу данных.
4. Разработать интерфейс программы.
5. Провести тестирование системы.
---
### Возможности системы
**Основные функции:**
- добавление клиентов;
- регистрация клиентов;
- запись на ремонт;
- учет услуг и запчастей;
- расчет стоимости ремонта;
- оформление оплаты;
- создание отчетов.
